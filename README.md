# Logolling
Proyecto Intermodular de 2º de DAM. Esta aplicación consiste en el intercambio de habilidades y favores entre usuarios.

Primero

  - Registrar usuario (HU-001) 3 horas IMPRESCINDIBLE
  - Inicio de sesión (HU-002) 2 horas IMPRESCINDIBLE
  - Crear publicación (HU-003) 4 horas IMPRESCINDIBLE
  
Segundo

  - Buscar servicios (HU-009) 5 horas IMPRESCINDIBLE 
  - Calendario de disponibilidad (HU-012) 3 horas IMPRESCINDIBLE
  - Ver perfiles de otros usuarios (HU-014) 4 horas IMPRESCINDIBLE
  
Tercero

  - Comunicación entre usuarios (HU-023) 5 horas IMPRESCINDIBLE
  - Borrar publicaciones (HU-005) 2 horas IMPRESCINDIBLE
  
Administrador:

  - Borrar publicaciones (HU-017) 2 horas IMPRESCINDIBLE
  - Borrar usuarios (HU-018) 3 horas IMPRESCINDIBLE
  - Atención al cliente (HU-021) 3 horas IMPRESCINDIBLE  
  - Contactar con usuarios (HU-022) 3 horas IMPRESCINDIBLE
  - Reportar publicaciones y usuarios (HU-015) 4 horas
  - Recuperar contraseñas (HU-020) 5 horas
  - Guardar publicaciones de otros usuarios (HU-010) 2 horas
  - Ver historial de servicios prestados/utilizados (HU-011) 2 horas
  - Editar perfil (HU-006) 4 horas
  - Editar publicaciones (HU-007) 2 horas
  - Añadir valoraciones (HU-008) 2 horas
